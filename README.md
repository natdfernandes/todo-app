# Todo App List
Projeto voltado ao aprendizado Full Stack.

O app todo list é um aplicativo voltado a salvar uma lista de itens de maneira simples, rápido e prático.

Auxiliando no dia-a-dia de usuários que querem manter a produtividade e a organização de itens de compras, produtos e qualquer outro item de preferencia do usuário.

Possui interface intuitiva e fácil de ser utilizada, buscando sempre a praticidade ao utilizar o todo app.

## Estrutura do Frontend
- HTML5 (estrutura básica);
- CSS3 sem nenhuma biblioteca adicional (estilização);
- JavaScript puro sem nenhum framework (lógica cliente).

## Estrutura do Backend
- Linguagem de programação Python;
- framework Flask.

### Rotas sugeridas
- `POST /criar` - Rota responsável por criar um novo item;
- `PUT /editar/:id` - Rota responsável por editar um item especifico por id;
- `DELETE /deletar/:id` - Rota responsável por deletar item por id;
- `GET /listar` - Rota responsável por listar todos os itens.
